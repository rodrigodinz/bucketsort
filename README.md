## 📝 Descrição do Projeto
<p align="justify">
Projeto desenvolvido para a disciplina de Estrutura de Dados 2 do curso de Análise e Desenvolvimento de Sistemas do Instituto Federal de São Paulo (IFSP). 

O objetivo principal foi construir o algoritmo de ordenação <strong>BucketSort</strong> em linguagem C. A aplicação é capaz de ler e processar dados brutos a partir de um arquivo estruturado (<code>Dados - Plan1.csv</code>), distribuindo as informações em "baldes" (buckets) para realizar a ordenação de forma otimizada. 

Este projeto foi uma etapa fundamental de engenharia e preparação de dados, pois a base ordenada aqui foi o requisito necessário para a realização de análises de dados em etapas posteriores da disciplina.
</p>

## 💻 Tecnologias Utilizadas
- **C:** Linguagem principal utilizada para a lógica de estruturas de dados e manipulação de ponteiros.
- **Manipulação de Arquivos:** Leitura e processamento de arquivos `.csv`.
